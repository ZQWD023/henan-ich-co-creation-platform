# 提交包修订说明（只需替换 2 个 md，不用重打视频和 PDF）

## 做了什么

| 文件 | 改动 |
|---|---|
| `00_提交说明与自检报告.md` | 修正 Git 历史口径：`main` 实际 **49 次提交**（原稿写"5 次"，与仓库不符，评审一查就露）；顺带删掉"提交历史偏短"这条自相矛盾的风险项 |

## 怎么用

1. 打开你桌面的 `最终提交/` 目录；
2. 用本文件夹里的两个同名文件**覆盖**过去；
3. 其余文件（PDF / 视频 / 源码 zip / PPT / 封面）**完全不动**，不需要重打包；
4. 上传网盘时把 `00_提交说明与自检报告.md` 也带上（评委能看到自检过程，是加分项）。

## 还差的两件事（只能本人做）

2. **B 站**：上传 `03_演示视频_....mp4`（203 MB）→ 等审核通过、**转码出 1080P** → 复制视频链接（表单第 7 项）。
