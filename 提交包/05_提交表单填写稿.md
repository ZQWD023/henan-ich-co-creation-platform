**直接粘贴**：

```
河南省非物质文化遗产共创平台是一个把非遗知识库、AI 问答与真实创作协作串成闭环的 Web 作品。它不只让人"看"非遗，而是让会插画的学生、会烧窑的师傅、会写文案的人在一个项目里相遇。

平台收录 49 个河南非遗项目、10 大分类、18 位代表性传承人，每个项目拆解为源流、工艺流程、技艺看点与实拍图，共 506 条可检索语义片段。

AI 能力有四块：RAG 问答用 BM25 + 四层业务加权 + 实体闸门，回答必带检索依据、无据则拒答；共创 Agent 通过 5 个工具真实调用，把一句需求拆成任务清单与项目简报，并可一键发布为在招共创项目；端侧多模态支持以图搜非遗（72 维特征，图片不出浏览器）与确定性纹样生成；五个工具有标准 MCP 端点 /api/mcp 供外部 Agent 调用。

工程上：零构建前端 20 个页面同源、30 个单元测试、105 道检索评测、8 项自检脚本，无 Key/断网/后端未启动都不白屏。
```

> 若表单限 200 字，用下面这版精简：
