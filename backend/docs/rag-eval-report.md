## 五、这组数字说明了什么

1. **全部项目可被点名检索**（B 组）：说明切词与名称加权在小语料上可靠；

3. **描述型问题也能命中**（E 组）：问题里没有项目名时靠内容匹配，这是 BM25 + 分类加权的真实能力；
4. **越界题能拒答**（A 组 3 道）：实体闸门生效，是"AI 安全与可控性"里"不编造依据"的证据；
5. **Agent 确定性**：5 个目标全部识别到正确项目并产出 5 步轨迹与任务清单。

## 六、已知不足（评委可能追问的）

- 检索是 BM25 + 规则加权，不是向量检索：同义改写（"钧窑" vs "钧瓷"）依赖别名词表，覆盖不全；
- B 组题目偏简单（含项目名），会把总体 Top-1 拉高；请看第二节分组表，不要只看总数；
- 关键词覆盖率是字符串匹配，无法判断语义是否真的正确（需人工复核）；
- 用例由同一团队编写与标注，存在"自己出题自己考"的偏差，需要第三方复核。
