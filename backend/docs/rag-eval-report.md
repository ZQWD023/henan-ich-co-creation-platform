## 四、这组数字说明了什么

1. **检索确实提升了定向性**：直接点名的 16 道题里，Top-1 命中率与项目名整体加权（×1.5）直接相关；
2. **分类意图加权（×1.8）有效**：问"河南有哪些戏曲"时，8 个传统戏剧项目会一起进候选，而不是只回一个；
3. **越界题能拒答**：3 道无关问题（天气/代码/自我介绍）没有返回知识库片段，说明实体闸门生效，
   这也是"AI 安全与可控性"里"不编造依据"的具体证据；
4. **Agent 的确定性**：5 个目标全部识别到正确项目并产出 5 步轨迹，方案含标题、描述、任务清单——
   这是"产出可直接发布"的前提。

## 五、已知不足（评委可能追问的）

- 检索是 BM25 + 规则加权，不是向量检索：同义改写（如"钧窑"vs"钧瓷"）依赖别名词表，覆盖不全；
- 评测集规模小（24 题），只能作为方向性验证，不能当作统计显著的结论；
- 关键词覆盖率是字符串匹配，无法判断语义是否真的正确（需要人工复核）。
