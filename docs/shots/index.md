## 二、录制执行单（照着做，2-3 小时能录完）

**准备（10 分钟）**

1. 双击 `启动网站.bat`，确认 <http://localhost:3000/> 能打开；
2. 跑一次 `npm run verify`（8 项全过再录）；
3. 浏览器**全屏（F11）**，缩放 100%，关掉多余标签页；
4. 登录 `creator / 123456`（演示"发布"需要登录）；
5. 录屏软件设 **1920×1080 / 30fps / 麦克风开启**；
6. 微信、输入法候选框、系统通知全部关掉。

**分段录（每段单独录，错了只重录这一段）**

| 段 | 时长 | 内容 | 对应素材 |
|---|---|---|---|
| 1 | 50s | 开场 + 痛点（口播稿 P1-P2） | `01-home.png`、`02-stats.png` |
| 2 | 40s | 产品全景 + 项目库（P3） | `03-library.png`、`04-detail.png` |
| 3 | 70s | AI 问答（P5 前段） | 现场操作，不用图 |
| 4 | 90s | **Agent 5 步 + 一键发布**（全片重点） | `06-ai-lab-agent.png` |
| 5 | 50s | 多模态两连（以图搜非遗 + 纹样生成） | `07`、`08` |
| 6 | 60s | 共创广场 / 工作台 / 活动（P9 前） | `09`、`10`、`11`、`12` |

| 8 | 30s | 收尾（P13） | 回到首页 |

**剪辑（30 分钟）**

- 剪掉加载等待、鼠标乱晃；每段之间加 0.3s 淡入；
- 关键处加字幕：`Top-1 100%`、`5 步工具调用`、`一键发布`；
- 导出 **MP4 / H.264 / 1080p / 码率 6-8 Mbps**；
- 文件名：`传智杯_团队名_非遗共创平台_演示视频.mp4`；
