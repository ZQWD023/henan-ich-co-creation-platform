# 答辩预演评分表（自己给自己打分）

> 用法：预演 1 遍 → 按表打分 → 只改最低的 2 项 → 再预演 1 遍。
> 目标：**总分 ≥ 80**（满分 100）。低于 60 说明还要再练 2 遍。
> 配套：`docs/ppt/提词器.html`（逐页计时）、`docs/ppt/非遗共创平台-国赛答辩.pptx`。

## 一、时间控制（20 分）

| 项 | 标准 | 自评 |
|---|---|---|
| 总时长 | 8 分钟以内（超 10 分钟会被打断） | /8 |
| 单页不超时 | 提词器亮黄灯即收尾，红灯即跳页 | /6 |
| 演示环节 | 90 秒内跑完 Agent 5 步 + 跳转详情页 | /6 |

## 二、内容表达（30 分）

| 项 | 标准 | 自评 |
|---|---|---|
| 每页一句话结论 | 15 页里至少 10 页说得出一句"所以呢" | /8 |
| 数字准确 | Top-1 100%（105 题）、1.08ms、30 单测、-49.8%、16 页 PDF 一个不错 | /8 |
| 主动认边界 | 至少说出 1 处不足（评测自评、TS 只做类型检查） | /7 |
| 不念 PPT | 没有一页是逐字念下来的 | /7 |

## 三、技术应答（30 分）

| 项 | 标准 | 自评 |
|---|---|---|
| Q1 和直接调大模型的区别 | 30 秒内答完，含"依据可点 + 无 Key 能跑 + 产出落库" | /10 |
| Q2 为什么不用向量检索/现代框架 | 承认代价 + 说明取舍 + 给出下一步 | /10 |
| Q3 模型挂了/断网 | 四层兜底一口气说完 | /10 |

> 加分：能现场跑一个新需求（评委报一个非遗项目名 → 跑 Agent）。

## 四、现场状态（20 分）

| 项 | 标准 | 自评 |
|---|---|---|
| 语速 | 每分钟 220-260 字，关键术语前有停顿 | /5 |
| 目光 | 看评委，不看屏幕超过 3 秒 | /5 |
| 演示保险 | 说得出"如果卡住我怎么接"（口播稿里那句） | /5 |
| 收尾 | 说完"让手艺被看见"就停，不补话 | /5 |

## 五、扣分项（出现即扣 5-10 分）

- [ ] 现场发布会改数据（应停在"跳转详情页"）
- [ ] 说"这个我们还没做"超过 2 次（应提前准备"为什么先不做"）
- [ ] 提到"抄/参考了某个开源项目"却说不出改了什么
- [ ] 演示时切到后台/终端，让评委看命令行
- [ ] 结尾拖时间，反复"谢谢老师"
